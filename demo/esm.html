esm.sh CDN sanity check

This page loads the component class from esm.sh and registers it manually. It requires the package version below to be published; the local demo does not depend on a CDN.

Import and register the class

<script type="module">
  import { ScriptDependentElement } from
    'https://esm.sh/@aarongustafson/script-dependent@1.0.0/script-dependent.js?bundle&target=es2022';

  if (!customElements.get('script-dependent')) {
    customElements.define(
      'script-dependent',
      ScriptDependentElement,
    );
  }
</script>
